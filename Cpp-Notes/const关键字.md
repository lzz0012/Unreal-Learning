# const用法
## 声明一个不再改变的常量
```c++
    const int a = 5;
```
## 应用于指针
```c++
const int* a = 5; //不能改变指针指向的内容，常量指针
int* const a = 5; //不能重新赋值指针指向其他地址,指针常量
```

## 应用于类方法
```c++
int GetX() const
{
    //该方法内不能修改成员变量
}

void PrintEntity(const Entity& e)
{
    e.GetX();
}
```
> [!NOTE]
> 当我们将一个类实例通过常量引用传递给函数时，也就意味着这个类的内容不能修改，引用本身不能修改。所以此时如果在函数体内调用类中没有const关键字的方法，编译器会认为这个方法可能会改变类成员变量，与const产生冲突。
