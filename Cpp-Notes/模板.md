# 模板template
```c++
template<typename T>
void Print(T value)
{
    std::cout << value << std::endl;
}
int main()
{
    Print<int>(4);
}
```
> [!NOTE]
> Print函数是一个模板，只有当我们调用这个函数时，编译器才会使用我们提供的参数实际创建函数

数组大小应该在编译期确认，而模板也会在编译期被处理。

```c++
template<typename T,int N>
class Array
{
private:
    T m_Array[N]；
public:
    int GetSize() const 
    {
        return N;
    }
}
```
