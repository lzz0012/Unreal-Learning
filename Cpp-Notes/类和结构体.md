## 类
创建一个类类型变量的过程叫做实例化

```c++
class Player
{
public:
    int x,y;
    int speed;

    void Move(int xa,int ya)
    {
        x += xa * speed;
        y += ya * speed;
    }
};
```

> [!NOTE]
> 默认情况下，类中成员的访问控制为私有。即只有类内部的函数才能访问这些变量

## 结构体
struct和class的最大区别在于:默认情况下struct的访问控制为public,class的访问控制为private

> [!NOTE]
> ### 使用类和结构体的时机
> - 当涉及plain old data或者只包含一些变量的结构时，偏向于用结构体，例如向量类。
>   - plain old data主要由基本类型和其他简单成员构成，没有自定义构造，析构等复杂声明周期逻辑
> - 当存在继承关系时不应该使用struct而是class

## 简单log类
```c++
class Log
{
public:
    const int LogLevelError = 0;
    const int LogLevelWarn = 1;
    const int LogLevelInfo = 2;
private:
    int m_LogLevel = LogLevelInfo;
public:
    void SetLogLevel(int level)
    {
        m_LogLevel = level;
    }

    void Error(const char* message)
    {
        if(m_LogLevel >= LogLevelError)
            std::cout << "[ERROR]: " << message << std::endl;
    }

    void Warn(const char* message)
    {
        if(m_LogLevel >= LogLevelWarn)
            std::cout << "[WARNING]: " << message << std::endl;
    }

    void Info(const char* message)
    {
        if(m_LogLevel >= LogLevelInfo)
            std::cout << "[INFO]: " << message << std::endl;
    }
};
