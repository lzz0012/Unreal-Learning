# 声明与定义
## 声明:告诉编译器这个symbol存在以及其类型，不分配内存
- 变量声明:  

```c++
extern int a;
```

- 函数声明:  
  
```c++
  int add(int x, int y);   // 声明，只有签名，没有函数体
```

## 定义：告诉编译器这个symbol具体的实现，分配内存，提供函数体
- 变量定义:  
  
```c++
    int a; //默认初始化
    int b = 10; // 有初始化就有定义
```
- 函数定义：

```c++
    int add(int x, int y) {  // 定义，有函数体
    return x + y;
}
```
