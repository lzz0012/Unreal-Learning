## 拷贝构造函数
c++类默认提供的拷贝构造函数类似于：
```c++
class String
{
    //拷贝构造函数
    String(const String& other)
    {
        memcpy(this, &other, sizeof(String));
    }
}
```
> [!NOTE]
> 但是默认的拷贝构造函数是一种浅拷贝  
> 指针：  
> 浅拷贝:只复制指针本身  
> 深拷贝:不仅复制指针而且复制指针指向的内容

## 禁用默认拷贝构造函数，手动编写一个简易的深拷贝构造函数
```c++
class String
{
private:
	char* Buffer;
	unsigned int m_Size;

public:
	String(const char* string)
	{
		m_Size = strlen(string);
		Buffer = new char[m_Size + 1];
		memcpy(Buffer, string, m_Size + 1);
	}
	~String()
	{
		delete[] Buffer;
	}

    String(const String& other) = delete;
    //深拷贝构造函数
    String(const String& other)
        :m_Size(other.m_Size)
    {
        Buffer = new char[m_Size + 1];
        memcpy(Buffer, other.Buffer, m_Size + 1);
    }

	friend std::ostream& operator<<(std::ostream& stream, const String
		& string);
};

std::ostream& operator<<(std::ostream& stream, const String& string)
{
	return stream << string.Buffer;
}
```
