## 继承
把一系列类的通用代码放到基类中,并在此基础上创建派生类修改原有功能或创建新功能

## 虚函数
虚函数可以让我在子类中重写父类的方法  
虚表是一个包含类中所有虚函数映射的列表，通过虚表可以在运行时找到正确的被重写的函数  
虚表是实现多态的核心机制，每个含有虚函数的类，编译器会为它生成一张虚表，每个该类的对象，会在内存布局的最前面插入一个虚表指针指向该类的虚表。  
虚函数的代价:  
- 需要额外的内存用来存储虚表
- 每次调用虚函数时，需要遍历虚表去找到最终要运行的函数

```c++
class Entity
{
public:
    virtual std::string GetName()
    {
        return "Entity";
    }
};
class Player : public Entity
{
private:
    std::string m_Name;
public:
    Player(const std::string& name)
        : m_Name(name){}
    
    std::string GetName() override 
    {
        return m_Name;
    }
}
```

## 纯虚函数
**纯虚函数允许我们定义一个在基类中没有实现的函数，然后交由子类来实现该函数**  
``` virtual std::string GetClassName() = 0;```
### 虚函数 vs 纯虚函数
对于基类的虚函数，子类可以选择性地去实现  
对于基类的纯虚函数，子类必须实现
