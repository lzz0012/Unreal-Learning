## 构造函数
- 在创建一个实例时运行
- 没有返回值
- 构造函数名称与类名一致
- 类默认存在一个构造函数，这个构造函数不接受参数，函数体也什么都不做
- 先调用父类的构造函数再调用子类的构造函数
  

> [!NOTE]
> 如果不希望创建类实例
> - 通过private隐藏构造函数
> - 删除构造函数

```c++
class Log
{
private:
    Log(){}

public:
    Log() = delete;
}
```
### 初始化列表
```c++
class Entity
{
private:
    std::string m_Name;
    int m_score;
public:
    Entity()
        : m_Name("Unknown"), m_score(0)
    {

    }
}
```
> [!NOTE]
> 初始化列表的顺序与类成员变量的定义顺序一致
> 如果一个类作为另一个类的成员变量，使用初始化列表可以避免重复创建对象。
## 析构函数
- 在销毁实例时运行
- 用于释放内容和清理内存空间
- 和构造函数唯一的区别在于要在前面加上~
- 先调用子类的析构函数，再调用父类的析构函数

### 虚析构函数
> [!NOTE]
> 在处理多态时，不同于普通虚函数，只调用子类覆写的函数，虚析构函数表示可能子类中还有其他析构函数需要被调用。即不仅会调用子类的析构函数还会调用父类的析构函数。  
> 如果父类的析构函数不设置为虚析构函数，那么在应用多态时会导致子类的析构函数不被调用，可能导致内存泄漏的问题。
