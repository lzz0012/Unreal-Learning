# 函数指针
函数指针是将一个函数赋值给变量的方法  
函数指针还可以将函数作为参数传递给其他函数
```c++
void HelloWorld()
{
	std::cout << "Hello, World!" << std::endl;
}
int main()
{
	typedef void(*Function)();
	Function function1 = HelloWorld;
	auto funciton2 = HelloWorld;
    //auto == void(*)()函数指针类型
    //void(*)()别名=Funciton
    functin();//调用函数HelloWorld
}
