# 智能指针
智能指针自动实现释放new分配的内存，无需手动调用
delete。
> [!NOTE]
> 智能指针的头文件\<memory\>
## unique_ptr作用域指针
unique_ptr本质上是栈对象，当这个指针超出作用域时，它会被销毁，随之指向的对象内存也被释放。
unique_ptr是当你想要一个作用域指针时，对你真正想要的指针的唯一引用，不能复制,复制会导致内存泄漏。不能复制是因为copy被删除。  
```unique_ptr(const unique_ptr&)            = delete；```
```unique_ptr& operator=(const unique_ptr&) = delete;```
> [!CAUTION]
> unique_ptr智能指针的构造函数使用了explicit修饰，即创建该智能指针必须显示调用其构造函数，不能依靠隐式构造函数转换。

```c++
#include <iostream>
#include <memory>

class Entity
{
public:
	Entity()
	{
		std::cout << "Created Entity!" << std::endl;
	}
	~Entity()
	{
		std::cout << "Destroyed Entity!" << std::endl;
	}
};
    std::unique_ptr<Entity> entity(new Entity());
    //更安全的方法，避免碰巧在构造函数抛出异常，得到一个没有引用的空指针而导致内存泄漏
    std::unique_ptr<Entity> entity = std::make_unique<Entity>();
```

## shared_ptr共享指针
**机制是引用计数，引用计数是一种跟踪统计指针有多少引用的方法，当计数归0，释放指向对象的内存**
> [!NOTE]
> shared_ptr会额外分配一块叫做控制块的内存，用来存储引用计数
```c++
//这种分配方式会出现两次内存分配，先分配new Entity,再分配控制块。
std::shared_ptr<Entity> sharedEntity(new Entity());
//这是更高效的分配方式
std::shared_ptr<Entity> sharedEntity = std::make_shared<Entity>();
```

## weak_ptr
**当把shared_ptr赋值给weak_ptr时，不会增加引用计数，所以在使用weak_ptr时需要询问底层对象是否存活**

> [!TIP]
> unique_ptr vs shared_ptr  
> unique_ptr：  
> 开销低，但不能共享  
> shared_ptr：  
> 可以共享，但需要控制块来计数，产生额外开销  
> 优先级：unique_ptr > shared_ptr
