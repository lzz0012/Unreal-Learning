前向声明（Forward Declaration） 是只告诉编译器“有这么个类型存在”，但不给出其完整定义。它在虚幻引擎代码里极其常见，主要用来减少头文件包含、加快编译、打破循环依赖。

class UStaticMeshComponent;   // 前向声明

它只引入一个不完整类型（incomplete type），编译器知道这个名字代表一个类型，但不知道它有多大、有哪些成员。

虚幻引擎中的典型用法

1. 头文件中前向声明，源文件中包含

2. 打破循环依赖,如果两个头文件互相 #include，就会形成循环依赖，编译报错或行为异常。前向声明配合源文件里的 #include 是标准解法。

前向声明 = “这个名字是个类型，细节稍后告诉你”。

它只够用来声明指针 / 引用 / 函数签名。

真正使用该类型的成员或创建对象时，必须在源文件里 #include 完整头文件。

在 UE 中，它是减少头文件依赖、加快编译、解决循环依赖的常规手段，且与 UPROPERTY 指针成员兼容。
