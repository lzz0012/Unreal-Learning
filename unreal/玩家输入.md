# 玩家输入绑定
- 在c++ 你的项目.build.cs中添加EnhancedInput模块
- 在内容浏览器创建InputAction,定义好需要哪些行为，根据行为设置Value Type
  - Value Type:
    - Digital (bool)	bool	开关型动作，只有“按下/松开”两种状态	跳跃、开火、交互、冲刺
    - Axis1D (float)	float	单轴连续值，通常表示一个方向上的力度或速度	油门、刹车、左右转向、缩放
    - Axis2D (Vector2D)	FVector2D	二维平面上的方向与力度	WASD 移动、摇杆移动、鼠标视角
    - Axis3D (Vector)	FVector	三维空间中的方向与力度	飞行器六自由度操控、特殊载具
- 创建InputMappingContext,将InputAction绑定到对应的按键，并使用Modifiers生成合适的值
- 编写角色头文件，添加指向InputAction和InputMappingContext的指针，以及创建输入触发的回调函数
- 在BeginPlay中将IMC注册到本地玩家子系统
- 在 SetupPlayerInputComponent 中绑定动作，根据动作类型选择合适的触发事件。ETriggerEvent::Triggered 适合连续输入（如移动），而 Started/Completed 适合开关型输入（如跳跃），SetupPlayerInputComponent由引擎在玩家控制器成功 Possess 这个 Pawn 之后自动调用。
