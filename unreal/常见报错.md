## vs显示实时编码模式当前处于活动状态，这可能导致生成失败，如果遇到生成失败，请尝试关闭Ureal编辑器或禁用实时编码
这个报错是因为虚幻引擎 5 默认开启了 Live Coding（实时编码） 功能，它占用了编译通道，导致 Visual Studio 无法正常进行常规构建
- 方案一：临时编译（保持编辑器开启）
如果你正在编辑器里测试，不想关闭它，不要在 VS 里点生成。请直接在 虚幻编辑器 中按下快捷键 Ctrl + Alt + F11。这会触发 Live Coding 编译，修改的代码效果会立即生效，无需重启。
- 方案二：彻底关闭 Live Coding（适合常规 VS 开发）
如果你习惯在 Visual Studio 里进行完整的编译和调试，建议直接禁用该功能：
    - 打开虚幻编辑器，点击顶部菜单 编辑 > 编辑器偏好设置。
    - 在左侧找到 通用 > Live Coding。
    - 取消勾选 启用 Live Coding（Enable Live Coding）。
    - 重启虚幻编辑器和 Visual Studio 即可正常生成
  
## 仅仅只在修改函数体的时候使用Live coding,其他情况尽量使用IDE编译
> [!CAUTION]
> 当你用 Live Coding 在编辑器开着的情况下编译 C++ 代码时，Reinstancing 决定了引擎是否要替换掉内存中已经存在的对象（比如蓝图实例、CDO），让它们用上刚编译出来的新类定义
> Live Coding 配合 Reinstancing 使用，有永久损坏蓝图资产的风险
> 推荐的安全配置是 “开启 Live Coding，但关闭 Reinstancing”
