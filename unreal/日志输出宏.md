# UE_LOG
UE_LOG 是 Unreal Engine 中 C++ 代码里最常用的日志输出宏。它可以把信息打印到输出日志（Output Log）窗口、控制台，或写入日志文件

```c++
UE_LOG(LogCategory, Verbosity, Format, ...);  
格式化输出字符串必须用 TEXT() 包裹，否则在非 ASCII 环境会出问题,例如：  
UE_LOG(LogTemp, Warning, TEXT("This is a warning"));
```

| 参数 | 说明 | 城市 |
|:---:|:----|-----:|
| LogCategory | 日志分类，如 LogTemp、LogGameplay   | 
| Verbosity | 日志级别，如 Log、Warning、Error   | 
|Format|格式化字符串（类似 printf）|
|...|可变参数，填充格式占位符|
