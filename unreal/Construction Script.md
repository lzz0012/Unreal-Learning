# Construction Script
UE 蓝图的 Construction Script（构造脚本） 的核心执行时机是在 Actor 被创建或发生变更时，且总是在 BeginPlay 之前。它的主要作用是根据当前环境或自身属性，在游戏逻辑运行前完成 Actor 的初始化配置。

在编辑器中（设计阶段）

放置或修改时：当你把蓝图拖入关卡，或者在细节面板中修改了任何属性、移动/旋转/缩放 Actor 时，构造脚本会立即执行，以便你实时看到调整效果。

加载关卡时：打开包含该蓝图实例的关卡，引擎可能会重新运行构造脚本，以确保组件和属性与最新版本的蓝图匹配。

在运行时（游戏启动后）

动态生成时：当代码或逻辑在游戏运行中动态 Spawn 一个该蓝图的实例时，构造脚本会执行一次。

初始化阶段：对于已放置在关卡中的 Actor，游戏启动时构造脚本会运行，但其主要计算通常在打包时已“烘焙”完成。
