# 透视视图
## 在视口中环顾
- 按住LMB + 拖动鼠标
    - 前后移动摄像机，并左右旋转。

- 按住RMB + 拖动鼠标
    - 旋转摄像机以环顾关卡。

- 按住LMB + 按住RMB + 拖动鼠标
    - 使摄像机上移、下移、左移或右移，且不旋转摄像机。

## 在视口中移动
- 向上或向下滚动MMB
    - 使摄像机逐渐前移或后移。

- 按住RMB + 向上或向下滚动鼠标滚轮
    - 增加/降低摄像机的移动速度。

- 按住RMB + W / 数字键盘8 / 上箭头
    - 使摄像机前移。

- 按住RMB + S / 数字键盘2 / 下箭头
    - 使摄像机后移。

- 按住RMB + A / 数字键盘4 / 左箭头
    - 使摄像机左移。

- 按住RMB + D / 数字键盘6 / 右箭头
    - 使摄像机右移。

- 按住RMB + E / 数字键盘9 / 向上翻页
    - 使摄像机上移。

- 按住RMB + Q / 数字键盘7 / 向下翻页
    - 使摄像机下移。

- 按住RMB + Z / 数字键盘1
    - 抬升摄像机的视野。

- 按住RMB + C / 数字键盘3
    - 降低摄像机的视野。
